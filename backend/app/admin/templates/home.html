Это экспертный контур Hvostun.pro для разметки данных.

Здесь работают эксперты и администраторы проекта. Владельцы собак сюда не заходят: пользовательское приложение Hvostun развивается отдельно. Ваша разметка станет обучающими данными для модели.

О проекте

Hvostun помогает собаке и новой семье пройти адаптацию после пристройства из приюта. Модель оценивает риск трудностей с поведением для конкретной собаки и подбирает рекомендации под её профиль.

Основа оценки — опросник поведения C-BARQ. Владельцы отвечают на вопросы о собаке, а эксперты сопоставляют ответы с рекомендациями.

Подробнее о проекте: hvostun.com

Как размечать — по шагам

Ваша задача: для каждой сессии назначить рекомендации собаке (важность, критичность, при необходимости комментарий). Ниже — порядок работы.

  1. 1

    Откройте список сессий

    Раздел Ответы → выберите собаку. Колонка «Моя оценка» показывает, какие сессии вы уже разметили.

  2. 2

    Сначала сводка, потом детали

    На карточке откройте вкладку «Сводка» и прочитайте «Рассказ для эксперта» — картина поведения уже дома и то, что сказали в приюте. Для уточнений смотрите профиль собаки и ответы («По доменам» / «Все вопросы»). Баллы доменов — от 0 до 10.

  3. 3

    Назначьте рекомендации

    В блоке «Рекомендации» (вверху карточки) добавьте пункты из каталога для этой собаки/сессии: выберите важность и критичность, при необходимости напишите комментарий → «Сохранить».

  4. 4

    Переходите к следующей сессии

    Вернитесь в Ответы и возьмите следующую без вашей оценки.

Начать разметку → Ответы

Рассказ на сводке — черновик от GigaChat, чтобы быстрее собрать картину поведения. Решение о рекомендациях всегда за экспертом.
